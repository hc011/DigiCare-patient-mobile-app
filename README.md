# DigiCare

## Requirements

Before you start, ensure you have the following installed:

1. **Node.js and npm**: Necessary for running the project and managing its dependencies. For help installing Node.js and npm, follow this [installation guide](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm).
2. **Expo CLI**: A command-line tool that enables you to run React Native apps. For a beginner's guide to mobile development with Expo and React Native, see this [helpful article](https://dev.to/itminds/a-beginners-guide-to-mobile-development-in-react-native-with-expo-4f2o#:~:text=You%20need%20to%20have%20node%20and%20npm%20installed%2C,the%20command%20line%20tools%20npm%20install%20--global%20expo-cli).

## Getting Started

To start the project, follow these steps:

1. **Install Required Packages**: First, install all the required packages by running the following command in the project directory:
    ```bash
    npm i
    ```
2. **Download Expo Mobile App**: Then, download the Expo mobile app on your smartphone. The app is simply named "Expo".

3. **Start the Project**: Finally, run `expo start` or `npx expo start` and scan the QR code from the app to start the project.

4. **Set Up Backend Server**: Check your current IP address with `ipconfig`, and always start the server with `python manage.py runserver <Your-IP-Address>:8000`. Also, reset the IP address in `DigiCare/assets/IPAddress.js` to your current IP address.
