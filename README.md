# DigiCare

requirements - 

1.Node and npm - <a href = "https://docs.npmjs.com/downloading-and-installing-node-js-and-npm">help</a> <br>
2.expo - <a href ="https://dev.to/itminds/a-beginners-guide-to-mobile-development-in-react-native-with-expo-4f2o#:~:text=You%20need%20to%20have%20node%20and%20npm%20installed%2C,the%20command%20line%20tools%20npm%20install%20--global%20expo-cli">help</a> <br>

To start the project - 

1. First of all install all the required pakages by running following command in the project directory - <b> npm i </b> <br>
2. Then download expo mobile in your smartphone named as expo.<br>
3. Finally run <b>expo start</b> and scan the QR code from the app to start the project.
